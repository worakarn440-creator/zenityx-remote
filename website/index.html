ไม่รู้ว่า Mac ชิปอะไร? กดเมนู (Apple) → เกี่ยวกับ Mac เครื่องนี้ → ดูที่คำว่า ชิป (Chip) ถ้าเป็น Apple M… ให้เลือกปุ่มกลาง ถ้าเป็น Intel ให้เลือกปุ่มขวา
ฟรี 100%ไม่ต้องติดตั้งต้องกดอนุญาตก่อนทุกครั้ง

วิธีใช้ 3 ขั้นตอน

1

ดาวน์โหลดไฟล์

กดปุ่ม “ดาวน์โหลด” ด้านบน รอจนไฟล์โหลดเสร็จ (ไฟล์อยู่ในโฟลเดอร์ Downloads)

ถ้า Chrome ขึ้นเตือนว่าไฟล์ไม่ค่อยมีคนดาวน์โหลด ให้กดที่ ⋮ แล้วเลือก “เก็บไว้” (Keep) นี่เป็นปกติ เพราะแอปใหม่ ครูเป็นคนสร้างเอง

2

เปิดแอป

Windowsดับเบิลคลิกไฟล์ ZenityX-Remote.exe ถ้า Windows ขึ้นหน้าต่างสีฟ้าแบบนี้ ให้ทำตามภาพ:

Windows protected your PC
Microsoft Defender SmartScreen prevented an unrecognized app from starting.
More info ← กดตรงนี้ก่อน
Run anywayDon't run

กด More info แล้วจะมีปุ่ม Run anyway โผล่ขึ้นมา ให้กดปุ่มนั้น

Macทำตามนี้:

  1. ดับเบิลคลิกไฟล์ .dmg ที่โหลดมา แล้ว ลากไอคอน ZenityX Remote ไปใส่โฟลเดอร์ Applications
  2. เปิด ZenityX Remote จาก Applications (หรือ Launchpad) ครั้งแรกจะขึ้นว่า “ไม่สามารถเปิดได้” ให้กด “เสร็จสิ้น” ก่อน
  3. ไปที่ การตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย เลื่อนลงล่างสุด กดปุ่ม “เปิดแต่อย่างไรก็ตาม” (Open Anyway) แล้วใส่รหัสผ่านเครื่อง
  4. เปิดแอปอีกครั้ง กด “เปิด”
3

บอกรหัสให้ครู แล้วกด “อนุญาต”

เปิดแอปแล้วจะเห็น รหัส 9 หลัก ของเครื่องคุณ ส่งรหัสนี้ให้ครูทางแชต

123 456 789

เมื่อครูกดเชื่อมต่อ จะมีหน้าต่างถามบนจอคุณ ให้กด “อนุญาต” ถ้าไม่รู้จักผู้ขอ ให้กด “ไม่อนุญาต”

อยากหยุดเมื่อไรก็กดปุ่มสีแดง “หยุดแชร์” ได้ทันที

Macเครื่อง Mac ต้องเปิดสิทธิ์ 2 อย่างก่อน (ทำครั้งเดียว) ที่ การตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย

  1. การบันทึกหน้าจอ (Screen Recording) → เปิดสวิตช์ให้ ZenityX Remote เพื่อให้ครูเห็นจอ
  2. การช่วยการเข้าถึง (Accessibility) → เปิดสวิตช์ให้ ZenityX Remote เพื่อให้ครูควบคุมเมาส์/คีย์บอร์ดได้
  3. หลังเปิดสิทธิ์ ให้ ปิดแอปแล้วเปิดใหม่ ถ้าจะให้ครูแค่ดู ใช้แค่ข้อ 1 ก็พอ
🔒 ปลอดภัยแค่ไหน? ครูเข้าเครื่องคุณไม่ได้ถ้าคุณไม่กดอนุญาต และเลือก “ดูอย่างเดียว” ได้ ปิดแอปเมื่อไรก็ตัดการเชื่อมต่อทันที ภาพหน้าจอถูกเข้ารหัสระหว่างทาง

เจอปัญหา?

ปุ่ม “Run anyway” ไม่ขึ้น

ต้องกดคำว่า More info (ตัวหนังสือสีน้ำเงินใต้ข้อความ) ก่อน ปุ่ม Run anyway จึงจะโผล่ขึ้นมา

ดับเบิลคลิกแล้วไม่มีอะไรเกิดขึ้น

รอสักครู่ 5–10 วินาที แอปเปิดครั้งแรกจะช้ากว่าปกติ ถ้ายังไม่ขึ้น ให้คลิกขวาที่ไฟล์ → เลือก “เปิด” แล้วแจ้งครู

ขึ้นว่า “กำลังเชื่อมต่อเซิร์ฟเวอร์…” ไม่หาย

เช็กว่าอินเทอร์เน็ตใช้ได้ ปิดแล้วเปิดแอปใหม่ ถ้ายังไม่หาย ให้แจ้งครู

ครูขอเชื่อมต่อแต่ไม่เห็นหน้าต่างอนุญาต

ดูที่แถบงานด้านล่างจอ ไอคอนแอปอาจกะพริบอยู่ ให้คลิกที่ไอคอนนั้น

Mac: ครูเห็นหน้าจอเป็นสีดำ / ควบคุมไม่ได้

แปลว่ายังไม่ได้เปิดสิทธิ์ การบันทึกหน้าจอ และ การช่วยการเข้าถึง ตามขั้นตอนที่ 3 ด้านบน เปิดแล้วต้องปิดแอปแล้วเปิดใหม่

Mac: หาปุ่ม “เปิดแต่อย่างไรก็ตาม” ไม่เจอ

ต้องพยายามเปิดแอปก่อน 1 ครั้งจนขึ้นข้อความว่าเปิดไม่ได้ แล้วค่อยไปที่ การตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย เลื่อนลงล่างสุดจะเห็นปุ่ม (ปุ่มจะอยู่ให้กดแค่ประมาณ 1 ชั่วโมงหลังพยายามเปิด)

ใช้กับมือถือ / iPad ได้ไหม?

ยังไม่ได้ ตอนนี้ใช้ได้กับคอมพิวเตอร์ Windows 10/11 และ Mac เท่านั้น

ครูใช้ Windows นักเรียนใช้ Mac (หรือกลับกัน) ได้ไหม?

ได้ ใช้ข้ามกันได้ แอปจะแปลงปุ่ม Ctrl ↔ Command ให้เอง เช่น กด Ctrl+C ก็เป็นคัดลอกบน Mac

แอปนี้ปลอดภัยไหม ทำไม Windows ถึงเตือน?

Windows เตือนกับแอปทุกตัวที่ผู้พัฒนายังไม่ได้ซื้อใบรับรองเซ็นชื่อ (ราคาแพง) ไม่ได้แปลว่ามีไวรัส ดาวน์โหลดจากหน้านี้ที่ครูให้ลิงก์เท่านั้น อย่าโหลดจากที่อื่น
